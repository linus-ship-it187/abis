Die Boss-Rangliste. Rang 12 ist der Beste, Rang 1 der Schwächste. Nur der Boss trägt die Plätze ein.

    „Für alle speichern“ schreibt die Daten in die Datei data.json in deinem GitHub-Repository. Besucher sehen die Änderung nach dem nächsten Laden der Seite, spätestens nach zwei Minuten.

    Farm-Übersicht

    Gefarmte Waffenteile, Coltteile, Gusenberg-Teile und 50er-Teile. Das Kuchendiagramm zeigt, wer den größten Anteil hat.

    Boss-Modus

    GitHub-Token

    Damit der Boss für alle speichern kann, braucht diese Seite einen Token. Erstelle auf GitHub unter Settings, Developer settings, Personal access tokens, Fine-grained tokens einen Token nur für dieses Repository mit der Berechtigung „Contents: Read and write“. Der Token bleibt nur in diesem Browser gespeichert.
